# Network Security Dashboard

I built this project using Python and Streamlit to monitor network devices and check their connection status.

## Features
- Checks if network devices are online or offline.
- Shows ping response times in milliseconds.
- Displays results in a simple dashboard.
- Shows the total number of devices and how many are online or offline.

## Technologies Used
- Python
- Streamlit
- Subprocess
- Ping

## How to Run
1. Install Python.
2. Install Streamlit using `pip install streamlit`.
3. Download the project files.
4. Open a terminal in the project folder.
5. Run `python -m streamlit run dashboard.py`.

## Testing
I tested the dashboard using three IP addresses: 8.8.8.8, 1.1.1.1, and 9.9.9.9. All three responded successfully during testing.
